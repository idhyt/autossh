# atsh

A simple SSH connection manager with automatic passwordless login.

## Quick Start

```bash
# set encryption key for password storage
export ATSH_KEY="your-secret-key"

# add a server (password is read interactively)
atsh add -u devsecops -i 1.2.3.4 -n production

# login (first time authorizes the public key, then passwordless)
atsh login -i 1

# list all servers
atsh ls

# upload a file
atsh upload -i 1 -p ./app.conf /etc/app.conf

# download a file
atsh download -i 1 -p /var/log/app.log ./app.log

# run a command
atsh cmd -i 1 -c "systemctl restart nginx"
```

Data is stored in `$HOME/.atsh.d` (configurable via `ATSH_WORK_DIR`):

```
~/.atsh.d/
├── atsh.db           # SQLite database (passwords encrypted with ATSH_KEY)
├── id_rsa            # SSH private key (generated by `atsh ssh-keygen`)
├── id_rsa.pub        # SSH public key
├── config.toml       # SSH key path configuration
└── logs/             # Daily-rotated JSON logs
```

## Concepts

atsh manages **records** — each record stores the login credentials for one remote server. The password is encrypted with ChaCha20-Poly1305 using the `ATSH_KEY` environment variable.

**How passwordless login works:**

1. On first `login`, atsh uses the stored password to SSH in and appends your local public key to the remote's `~/.ssh/authorized_keys`.
2. Subsequent logins use your private key — no password needed.
3. Use `login --auth` to force re-authorization (e.g. after a password change).

## Commands

| Command | Aliases | Description |
|---------|---------|-------------|
| `add` | | Add a remote server (reads password interactively) |
| `ls` | `list`, `l` | List all servers |
| `login` | | Login to a server by index |
| `rm` | `remove`, `del`, `delete` | Remove one or more servers by index |
| `upload` | `up` | Upload a file via SFTP (with progress bar) |
| `download` | `down`, `dload` | Download a file via SFTP (with progress bar) |
| `cmd` | `command`, `run` | Run a command on a remote server |
| `ssh-keygen` | | Generate an SSH key pair for authentication |

### add

Requires `ATSH_KEY` to be set. Password is entered interactively (never appears in shell history).

```bash
atsh add -u devsecops -i 1.2.3.4 -P 22022 -n production -N "expires 2025-06"
```

| Option | Description |
|--------|-------------|
| `-u` | Login user (required) |
| `-i` | IP address (required) |
| `-P` | Port (default: 22) |
| `-n` | Alias name |
| `-N` | Note |

### login

```bash
atsh login -i 1         # login (authorizes first time if needed)
atsh login -i 1 --auth  # force re-authorization
```

### upload / download

Both show a progress bar during transfer. If the destination is a directory, the source filename is auto-appended.

```bash
atsh upload -i 1 -p ./local.txt /tmp/remote.txt
atsh upload -i 1 -p ./local.txt /tmp/          # creates /tmp/local.txt
atsh download -i 1 -p /tmp/remote.txt ./local.txt
```

### cmd

```bash
atsh cmd -i 1 -c "ls -la /tmp"
```

### ls

```bash
atsh ls             # basic info
atsh ls --all       # includes password, authorized status, notes
```

### ssh-keygen

Generate an RSA 2048-bit key pair for passwordless authentication:

```bash
atsh ssh-keygen              # interactive (no passphrase for keypair)
atsh ssh-keygen -p pass -s   # silent mode with password
```

### rm

```bash
atsh rm -i 1          # remove one
atsh rm -i 1 2 3      # remove multiple
```

## Library Usage

```rust
use atsh_lib::atsh::{self, Remote};

#[tokio::main]
async fn main() -> Result<(), atsh_lib::AtshError> {
    let ctx = atsh::initialize(Option::<&std::path::Path>::None)?;

    atsh::add(&ctx, "user", "password", "1.2.3.4", 22,
        &Some("my-server"), &None::<&str>)?;

    let remotes = atsh::get_all(&ctx)?;
    atsh::login(&ctx, remotes[0].index, false).await?;

    atsh::upload(&ctx, remotes[0].index, &["./file.txt", "/tmp/file.txt"]).await?;
    atsh::download(&ctx, remotes[0].index, &["/tmp/file.txt", "./file.txt"]).await?;
    atsh::run_command(&ctx, remotes[0].index, "uptime", (None, None)).await?;

    atsh::pprint(&ctx, true)?;
    Ok(())
}
```

## Build

Download pre-built binaries from [releases](https://github.com/idhyt/autossh/releases).

Or build from source:

```bash
git clone --depth=1 https://github.com/idhyt/autossh
cd autossh && cargo build --release
```

### Cross-compile

```bash
./xbuild          # interactive — select a target platform
./xbuild all      # build for all 5 targets
```

Supported targets: `x86_64-unknown-linux-musl`, `aarch64-unknown-linux-musl`, `x86_64-apple-darwin`, `aarch64-apple-darwin`, `x86_64-pc-windows-gnu`.

## Migration (from v0.3)

Use `tool.py` to migrate data from the old TOML-based format (v0.3.x) to the current SQLite format:

```bash
mkdir -p ~/.atsh.d
python tool.py toml2db -i ~/.config/autossh/config.toml -o ~/.atsh.d
```
